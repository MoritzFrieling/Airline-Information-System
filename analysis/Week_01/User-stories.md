## User stories

#sales employee
#### As a sales employee ... 

- *I want to look up flights to check whether a certain route is available* 

- *I want to create a booking to buy one or multiple tickets for the customer*

#### As a sales officer ... 

- *I want to register flights to start the sales process*

- *I want to update or delete flights if information for a certain flight changed*

- *I want to enable temporary price reductions to give customers a discount*

#### As a sales manager ... 

- *I want to inspect the management board to view the KPI’s (Key Performance Indicators) for specific routes*
- *I want to be able to register a new route so flights can be created*
- *I want to create accounts for the employees, that they can work with the system*
